# Vista de Mótu para Squarespace

`motu-code-block.html` es el bloque completo que se pega en una página de
Squarespace. Se genera desde `index.html` y `styles.css`; no se edita a mano.

## Vista previa segura

1. Ejecutar `npm test` para regenerar y comprobar el bloque.
2. En Squarespace, crear una página en **No enlazadas**.
3. Añadir una sección vacía y un bloque **Código**.
4. Pegar todo el contenido de `motu-code-block.html`.
5. Revisar escritorio y móvil antes de convertirla en la página de inicio.

La publicación, el dominio y cualquier cambio de DNS se hacen manualmente solo
después de aprobar esa vista previa.
